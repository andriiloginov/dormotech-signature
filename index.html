Install in Outlook

  1. Open Settings (gear icon) → Accounts → Signatures.
  2. Click Copy for Outlook above. Then click + New signature, name it Dormotech, click in the editor and paste (Ctrl+V / ⌘+V).
  3. Under Select default signatures, pick it for new messages and for replies/forwards. Click Save.
  1. In Outlook, open Outlook menu → Settings… → Signatures.
  2. Click Copy for Outlook above. Then click +, rename it Dormotech, delete the placeholder text and paste (⌘+V). Close the editor window to save.
  3. Under Choose default signature, pick it for new messages and replies/forwards.

Classic Outlook often reformats pasted signatures. Installing the file keeps the layout exact.

  1. Press Win+R, enter %APPDATA%\Microsoft\Signatures and press Enter. Move the downloaded Dormotech.htm into that folder.
  2. Restart Outlook, then go to File → Options → Mail → Signatures… and set Dormotech as the default for new messages and replies.
